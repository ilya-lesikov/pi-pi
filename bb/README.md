# pi-pi for bb

The bb plugin for [pi-pi](https://github.com/ilya-lesikov/pi-pi), the pi extension: in a bb thread running pi with pi-pi, it shows pi-pi's status line and menu, the task list and the workers above the composer, and draws pi-pi's questions as forms.

```
pi install npm:@ilya-lesikov/pi-pi
bb plugin install npm:@ilya-lesikov/bb-plugin-pi-pi
```

See the [bb section of pi-pi's README](https://github.com/ilya-lesikov/pi-pi#bb) for what it shows and how it works.
